# Not to Forget

Простое веб-приложение для планирования и организации задач, привычек и событий. Помогает пользователям не забывать о важных делах и эффективно управлять своим временем.

## О проекте

Проект "Not to Forget" разработан для создания удобного инструмента, который позволяет:
- Отслеживать ежедневные задачи.
- Формировать и контролировать привычки.
- Просматривать календарь.
- Получать информацию о планировании.

## Функционал

*   **Задачи:** Добавление, просмотр и управление списком задач.
*   **Привычки:** Добавление и отслеживание прогресса в формировании привычек.
*   **Календарь:** Отображение текущего месяца и дней недели.
*   **Персонализация:** Отображение имени пользователя и приветствия.
*   **Информация о планировании:** Переход на страницу с полезной информацией о планировании.

## Технологии

*   **HTML:** Структура веб-страниц.
*   **CSS:** Стилизация и оформление интерфейса.
*   **JavaScript:** Интерактивность и логика работы приложения.

## Установка и запуск

Для запуска проекта на локальной машине выполните следующие шаги:

1.  **Клонируйте репозиторий:**
    ```bash
    git clone https://github.com/pryfmse/coursework_web
    ```
2.  **Перейдите в директорию проекта:**
    ```bash
    cd курсовая_web
    ```
3.  **Откройте файл `index.html` в браузере.**
    Просто дважды щелкните по файлу `index.html` или откройте его через ваш веб-браузер.

## Структура проекта

*   `index.html`: Главная страница приложения.
*   `enter.html`: Страница входа/регистрации.
*   `about_planning.html`: Страница с информацией о планировании.
*   `script.js`: Основной JavaScript файл с логикой приложения.
*   `style_index.css`: Стили для главной страницы.
*   `style_enter.css`: Стили для страницы входа/регистрации.
*   `style_planning.css`: Стили для страницы "О планировании".
*   `отчет.docx`: Отчет по проекту.
